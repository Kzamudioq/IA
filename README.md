# Inteligencia Artificial en Python

Repositorio de implementaciones prácticas de algoritmos y modelos de inteligencia artificial: visión por computador, aprendizaje profundo, procesamiento de lenguaje natural y análisis de datos.

Los cuadernos se desarrollaron durante la **Maestría en Inteligencia Artificial Embebida de la Universidad de Buenos Aires** (2022–2024). Se publican como material de divulgación técnica, y varios tienen un video explicativo en el canal de YouTube de la autora.

**Autora:** Karen Tatiana Zamudio Quintero, Ingeniera Topográfica, Magíster en Inteligencia Artificial Embebida (UBA)
**Canal de YouTube:** [@KarenTatianaZamudioQuintero](https://www.youtube.com/@KarenTatianaZamudioQuintero/videos)

## Ejecución

Cada carpeta es independiente y contiene su cuaderno de Jupyter.

```bash
git clone https://github.com/Kzamudioq/IA.git
cd IA
jupyter notebook
```

Abra el cuaderno de la carpeta de interés e instale las bibliotecas que importe la primera celda.
